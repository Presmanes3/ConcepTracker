# Configuration

Runtime settings are stored in `config/settings.yaml`. The file is read at startup
by `src/repository/config_repository.py` and can be updated at runtime via
`PUT /config` or `ct config`.

---

## Top-Level Keys

### active_model_id

| Key | Type | Default | Description |
|---|---|---|---|
| active_model_id | string | `eu.amazon.nova-micro-v1:0` | Bedrock model identifier used for all LLM calls except `GeoNamerAgent`, which always uses `eu.amazon.nova-micro-v1:0` |

---

### audio

Audio input device selection.

| Key | Type | Default | Description |
|---|---|---|---|
| audio.input_device_id | int | `1` | System device index of the active recording device |

---

### pricing

Per-model cost configuration used by `CostService` to compute token spend.

| Key | Type | Description |
|---|---|---|
| pricing.\<model_id\>.input | float | USD per million input tokens |
| pricing.\<model_id\>.output | float | USD per million completion tokens |

Default entry:

| Model ID | Input (USD/1M) | Output (USD/1M) |
|---|---|---|
| eu.amazon.nova-micro-v1:0 | 0.035 | 0.14 |

---

### search

Controls the hybrid search pipeline parameters.

| Key | Type | Default | Description |
|---|---|---|---|
| search.expansion_count | int | `2` | Number of alternative queries generated by `QueryExpansionAgent` |
| search.top_k_before_rerank | int | `30` | Candidates retrieved from each of BM25 and vector search before fusion |
| search.rerank_top_n | int | `10` | Top N results passed to the reranker after RRF fusion |
| search.language | string | `simple` | PostgreSQL text search language (use `simple` for multi-language corpora) |
| search.reranker_model | string | `cohere.rerank-v3-5:0` | Bedrock Cohere reranker model identifier |
| search.rrf_k | int | `60` | Smoothing constant for Reciprocal Rank Fusion |

---

### services

Enables or disables backend service initialisation. Set to `false` to skip
a service on startup (useful for local dev without AWS credentials).

| Key | Type | Default | Description |
|---|---|---|---|
| services.bedrock | bool | `true` | Load `BedrockService` (LLM + embedding calls) |
| services.database | bool | `true` | Load `DatabaseService` (Postgres + pgvector) |
| services.transcribe | bool | `true` | Load `TranscribeService` (Amazon Transcribe streaming) |

---

### transcription

Settings for the real-time audio transcription pipeline.

| Key | Type | Default | Description |
|---|---|---|---|
| transcription.auto_pause_seconds | int | `30` | Seconds of silence before the recording session auto-pauses |
| transcription.enhancement_pipeline | string[] | `["speech_cleaner", "markdown_formatter"]` | Ordered list of enhancement stages to apply; valid values are `speech_cleaner` and `markdown_formatter` |

Setting `enhancement_pipeline` to an empty list disables all AI enhancement and
passes raw ASR output directly to the save step.

---

## Example File

```yaml
active_model_id: eu.amazon.nova-micro-v1:0

audio:
  input_device_id: 1

pricing:
  eu.amazon.nova-micro-v1:0:
    input: 0.035
    output: 0.14

search:
  expansion_count: 2
  top_k_before_rerank: 30
  rerank_top_n: 10
  language: simple
  reranker_model: cohere.rerank-v3-5:0
  rrf_k: 60

services:
  bedrock: true
  database: true
  transcribe: true

transcription:
  auto_pause_seconds: 30
  enhancement_pipeline:
    - speech_cleaner
    - markdown_formatter
```
